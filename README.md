# Internship Report

A personal internship report site built with [Hugo](https://gohugo.io/) and the
[hugo-theme-learn](https://github.com/matcornic/hugo-theme-learn) theme —
styled like [workshop-sample.awsfcaj.com](https://workshop-sample.awsfcaj.com/).

The site is bilingual (English / Vietnamese) and organized into 7 sections:

1. **Worklog** — 12 weekly work logs
2. **Proposal** — final capstone project proposal 
3. **Blogs Posted** — placeholder
4. **Events Participated** — AWS community/internal events 
5. **Workshop** — full hands-on serverless AI invoice scanner workshop 
6. **Self-Assessment** — placeholder
7. **Sharing and Feedback** — placeholder
