### Overview

* **Event Name:** AWS Knowledge Competition
* **Participation Period:** During the internship program
* **Technical Focus:** AWS Cloud Services, Cloud Architecture, AWS Solutions, Team Collaboration

---

### I. Summary of the Event

During my internship, I had the opportunity to participate in an AWS Knowledge Competition organized for trainees and interns. The competition featured **eight teams** competing through multiple rounds of questions covering AWS services and their practical applications in real-world scenarios.

#### 1. AWS Service Knowledge

The participating teams answered questions related to various core AWS services, including:

* Amazon IAM
* Amazon EC2
* Amazon S3
* Amazon VPC
* AWS Lambda
* Amazon API Gateway
* Amazon CloudWatch
* AWS CloudFormation

Besides testing theoretical knowledge, the competition also presented practical scenarios that required participants to select the most appropriate AWS services for designing efficient cloud solutions.

#### 2. Cloud Architecture Analysis

Several questions focused on analyzing cloud architectures and selecting suitable AWS services based on different requirements, including:

* Performance
* Cost optimization
* Security
* Scalability
* High availability

These challenges helped participants gain a deeper understanding of how multiple AWS services can be integrated into a complete cloud solution rather than being used independently.

#### 3. Team Collaboration

Each team was required to discuss the questions, analyze possible solutions, and submit answers within a limited time. The competition created an energetic atmosphere where communication, teamwork, and effective task distribution played an important role.

After several challenging rounds, the two highest-scoring teams advanced to the final round to compete for the championship.

---

### II. Lessons Learned

Through participating in this competition, I realized that mastering AWS involves much more than simply understanding the purpose of each service. More importantly, it requires the ability to apply cloud services effectively to solve practical business problems.

The explanations provided after each question helped me better understand cloud architecture design principles, service selection strategies, and the trade-offs between performance, security, scalability, and cost.

In addition to technical knowledge, I also recognized the importance of teamwork. The most successful teams demonstrated excellent communication, collaboration, and decision-making skills under time constraints.

---

### III. Knowledge and Skills Gained

By participating in this event, I gained valuable knowledge and practical experience, including:

* A deeper understanding of commonly used AWS services.
* Improved cloud architecture design skills.
* Better ability to select appropriate AWS services based on business requirements.
* A clearer understanding of how multiple AWS services work together within a complete cloud solution.
* Reinforcement of previously learned AWS concepts through practical scenarios.
* Exposure to different problem-solving approaches presented by other teams and the event organizers.
* Enhanced analytical thinking and cloud solution design skills.
* Greater appreciation for communication and teamwork in cloud computing projects.

---

### IV. Personal Reflection

This competition was one of the most valuable activities during my internship. It not only helped reinforce my AWS knowledge but also expanded my understanding of how AWS services are applied in real-world enterprise environments.

Observing how different teams analyzed problems and designed cloud solutions gave me valuable insights into AWS architecture design and the factors that should be considered when building cloud-based systems.

The event also motivated me to continue learning AWS services, practicing cloud solution development, and improving my cloud computing and system architecture skills for future projects.
